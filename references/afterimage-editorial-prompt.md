# 提示词指南（智企版）

## 默认：独立生成图

提示词写明：生成一张独立、无标题的纸感版画。原图仅作为视觉参考，成品里不包含照片、不拼图、不做前后对比。整个画幅是生成作品。

先指定实际尺寸比例和构图，再指定主体关系与笔触。来源颜色优先：深绿、灰绿、墨蓝等均可，不套固定颜色滤镜。保留主体关系而非照片的逐像素细节。

## 编译顺序

1. 交付：独立静态图（默认）/ 用户明确指定的其他交付。
2. 构图：主体位置、占比、留白、前后层次、比例。
3. 视觉语言：块面、叠层、轮廓、光影等。
4. 来源线索：主体、支持物、尺度、地平线/水面、主色和一点点色。
5. 字体：默认无任何文字；按用户要求添加时保持克制。
6. 动画思路：只有设计含义，静态中显示完整画面，不出现动画说明图形。

## 可适配的提示词

用所附照片作为参考，生成一张独立的纸感版画成品；不要在输出中放入原照片、摄影区域或对比拼图。采用[比例和构图]，以[主体关系]为中心，通过[视觉语言与笔触]压缩真实场景。保留[关键结构、姿态和空间关系]，从原图提取[颜色]，配温暖米白纸与适量留白。无标题、文字、水印和无关装饰。[若指定 motion seed：安排完整静态终态所需的清晰视觉组件，不输出动画、分镜、箭头或编号。]

不要把方括号占位符直接发送给工具；替换为针对当前照片的判断。

## social-cover

独立 9:16 图。主体约占宽度 60–80%，可按源照片建立前中后景；让关键主体在缩略图中可读。保留呼吸空间，避免顶边底边切断关键人物。不能把小图贴在大块空白底部，更不能加原图凑满上半幅。数值是构图目标，不能仅凭提示词声称成品精确达到。

## ink-assembly

按最大主体块 → 支持形 → 小点色/细线规划出现顺序。静态交付表现全体组件已出现的终态。组件视觉可辨识不等于实际分层；不要声称 PNG 内含独立图层。只有用户另要动画才进入制作阶段。

## 明确要求原图与生成图时

“分开给”意味着两个文件；“拼在一起/做对比图”才允许组合。组合图中的摄影区域不重绘、不改人物、不虚构景物；可以按用户许可裁切。原图保真是组合交付的约束，不是独立图的默认布局。

## 验收

检查交付是否独立、是否无文字、主体关系是否完整、是否满足所选构图、是否保持版画抽象。修改模式后与前一版比对实际结果。明显错误纠正一次。无法核验的尺寸、图层、动画或精确保真不得声称完成。
